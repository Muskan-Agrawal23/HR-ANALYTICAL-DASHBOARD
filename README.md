# 📊 HR Analytics Dashboard | Power BI

An interactive **HR Analytics Dashboard** built in **Power BI** to analyze employee attrition and workforce trends. This project transforms raw HR data into meaningful insights using **Power Query**, **DAX**, and interactive visualizations.

---

## 🚀 Project Overview

The dashboard helps HR teams understand employee attrition by analyzing key factors such as department, job role, age, salary, education, and gender. It provides actionable insights that support better workforce planning and decision-making.

---

## 📌 Key Features

- 📈 Employee Count, Attrition Count & Attrition Rate
- 💰 Average Salary Analysis
- 🎂 Average Employee Age
- 📅 Average Years at Company
- 🏢 Department-wise Attrition
- 🎓 Education Field Analysis
- 👨‍💼 Job Role-wise Attrition
- 👥 Gender-wise Attrition
- 💵 Salary Slab Analysis
- 📊 Interactive Filters & Slicers

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization


---

## 🎯 Business Insights

- Identify departments with the highest employee attrition.
- Analyze attrition trends across different age groups.
- Compare attrition based on salary slabs and education fields.
- Support HR decision-making with interactive visualizations.
